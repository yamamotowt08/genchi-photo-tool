# 現地調査写真整理ツール

現地調査で撮った写真を整理し、**写真位置図**と**写真台帳**を Word ファイル（.docx）にまとめる Windows 用のアプリです。
`現地写真整理ツール.exe` 1 つで動き、インストールは要りません。

## できること

1. **名前を変える**：フォルダ内の写真を、撮影日時の順などに並べて一括で名前を変えます（例：`現地踏査_01.jpeg`、`現地踏査_①.jpeg`）。変更前と変更後の一覧（CSV）を保存し、直前の変更は元に戻せます。
2. **写真位置図**：写真に記録された位置（GPS）と撮影方向をもとに、国土地理院の地図（地理院タイル）の上に矢印と番号を置きます。
   - 地図は、標準地図・淡色地図・写真・基盤地図情報から選べます。
   - 縮尺を 1:500〜1:50,000 から選べます（A3 で印刷したときの縮尺）。
   - 全体図の上をドラッグして四角で囲むと、その範囲の分割図（その1、その2…）を作れます。囲んだ数が分割図の枚数になり、全体図の下に並んで表示されます。描いた範囲は、四隅のつまみをドラッグして形を変えられます。分割図の名前（「その1」など）は、「A地区」のように自由に付けられます。写真の範囲で自動で並べることもできます。全体図には各分割図の範囲が枠で入ります。
   - 矢印と番号はドラッグで動かせ、向き・大きさ・色を変えられます。
   - 方位記号とスケールバーも、ドラッグで好きな場所に置けます。
   - 写真を対象から外して番号が飛んだときは、「番号を詰める」でファイル名ごと振り直せます。
   - 計画区域・測線・調査地点などの GIS データを重ねられます。読み込めるのは、シェープファイル（.shp .shx .dbf .prj .cpg）・ZIP・KML・KMZ・GeoJSON・JSON です。ファイルやフォルダを地図の上にドラッグしても読み込めます。
     - 色・線の太さ・線の種類・面の塗り・属性の文字を選べます。図形をクリックすると属性が出ます。重ねた図形は位置図の画像と Word にも入ります。
     - 座標系は、世界測地系（JGD2011・JGD2000）と旧日本測地系の緯度経度・平面直角座標系（第1〜19系）・UTM、Web メルカトルに対応しています。.prj がないときは、写真の位置から平面直角座標系の系を推定します。
3. **写真台帳**：写真ごとに説明を入力し、Word ファイルを作ります。
   - 最初のページから：写真位置図（A3 横、全体図・分割図の順）。矢印と番号は Word 上で動かせる図形にするか、地図の画像に組み込むかを選べます。
   - 2 ページ目以降：写真台帳（A4 縦・1 ページ 3 枚、「■No.」と説明文）。
   - 保存するときに、ファイル名と保存先を選べます。
   - 文字のフォント（ＭＳ ゴシック・ＭＳ 明朝など）と文字の大きさを選べます。
   - 番号の表記（「■No.1」など）を、`■No.{番号}`・`写真{丸数字}` のようなひな形で一括して変えられます。

## ダウンロード

[リリースのページ](https://github.com/yamamotowt08/genchi-photo-tool/releases/latest)から、次のファイルをダウンロードします。

- `GenchiPhotoTool.zip`：展開すると、アプリ `現地写真整理ツール.exe` と操作マニュアル `現地写真整理ツール_操作マニュアル.docx` が出てきます。
  （GitHub には日本語のファイル名を置けないため、ZIP の名前だけ英数字です。中の日本語の名前は、日本語の Windows で文字化けしないように入れてあります）

発行元の証明（電子署名）がないアプリなので、ダウンロードや初めての起動のときに、Windows やブラウザが確認の画面を出すことがあります。

- **Edge で「一般的にダウンロードされていません」と出たとき**：ダウンロードの一覧で、そのファイルの「…」→「保存」を押し、次の画面で「詳細表示」→「保持する」を押します。
- **「WindowsによってPCが保護されました」と出たとき**：「詳細情報」→「実行」を押します。
- **毎回確認が出ないようにするには**：ダウンロードしたファイルを右クリック →「プロパティ」→ 下の「セキュリティ」の「許可する」（ブロックの解除）にチェックを入れて「OK」を押します。共有フォルダに置く前にこれをしておくと、ほかの人も確認なしで使えます。

## 使い方

1. `現地写真整理ツール.exe` を、共有フォルダ（例：`\\newjec\dfs\…`）や自分のパソコンの好きな場所に置き、ダブルクリックします。
2. 「フォルダを選ぶ」で写真の入ったフォルダを選びます。
3. ①〜③の順に作業します。Word ファイルは、ファイル名と保存先を選んで保存します。
4. 新しい版にするときは、`現地写真整理ツール.exe` を新しいものに置き換えます。

### 必要なもの

- Windows 10 / 11（.NET Framework 4.8 と Microsoft Edge WebView2 ランタイムを使います。どちらも、ふつう最初から入っています）
- インターネット接続（国土地理院の地図を読み込むため）

### しくみ

- Windows に入っている Edge の部品（WebView2）でツールを表示します。ツールを「アプリの中だけの https のアドレス」で開くので、共有フォルダに置いたままでも、フォルダを選んで写真を読み書きできます。
- ツール本体と WebView2 を使うためのファイルは EXE の中に入っていて、起動したときに各自のパソコンの
  `%LOCALAPPDATA%\GenchiPhotoTool` に取り出して使います。共有フォルダには書き込みません。

### 作り直し方（開発用）

- ツール本体の元のファイルは `src/現地調査写真整理ツール.html`、アプリのソースは `app/` にあります。
- `python3 build_app.py --manual 操作マニュアル.docx` で、`dist/` に `現地写真整理ツール.exe`、マニュアル、それらを入れた `GenchiPhotoTool.zip` ができます（.NET 8 SDK が必要）。
  ツール本体は、`vendor/` の部品を取り込んだうえで EXE の中に入ります。

## データの扱い

- 写真や入力内容は、選んだフォルダの中だけで扱います。どこかのサーバーに送ることはありません。
- 入力した説明や、直した位置・向きなどは、フォルダ内の `写真整理データ.json` に自動で保存されます。次に同じフォルダを開くと続きから作業できます。
- 重ねた GIS データは、フォルダ内の `写真整理データ_GIS.json` に保存されます（元の GIS ファイルは変更しません）。

## 地図の出典

地図には国土地理院の地理院タイルと、基盤地図情報（ベクトルタイル提供実験）を使っています。位置図には出典が自動で入ります。
基盤地図情報は国土地理院の試験配信のデータを使っているため、配信の内容が変わったり、終わったりすることがあります。
報告書などに使うときは、[国土地理院の利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)を確認してください。
