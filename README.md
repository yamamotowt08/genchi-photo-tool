# 現地調査写真整理ツール

現地調査で撮った写真を整理し、**写真位置図**と**写真台帳**を Word ファイル（.docx）にまとめるツールです。
HTML ファイル 1 つで動き、インストールは要りません。

## できること

1. **名前を変える**：フォルダ内の写真を、撮影日時の順などに並べて一括で名前を変えます（例：`現地踏査_01.jpeg`、`現地踏査_①.jpeg`）。変更前と変更後の一覧（CSV）を保存し、直前の変更は元に戻せます。
2. **写真位置図**：写真に記録された位置（GPS）と撮影方向をもとに、国土地理院の地図（地理院タイル）の上に矢印と番号を置きます。
   - 地図は、標準地図・淡色地図・写真・基盤地図情報から選べます。
   - 縮尺を 1:500〜1:50,000 から選べます（A3 で印刷したときの縮尺）。
   - 全体図の上をドラッグして四角で囲むと、その範囲の分割図（その1、その2…）を作れます。囲んだ数が分割図の枚数になり、全体図の下に並んで表示されます。描いた範囲は、四隅のつまみをドラッグして形を変えられます。写真の範囲で自動で並べることもできます。全体図には各分割図の範囲が枠で入ります。
   - 矢印と番号はドラッグで動かせ、向き・大きさ・色を変えられます。
   - 方位記号とスケールバーも、ドラッグで好きな場所に置けます。
   - 写真を対象から外して番号が飛んだときは、「番号を詰める」でファイル名ごと振り直せます。
3. **写真台帳**：写真ごとに説明を入力し、Word ファイルを作ります。
   - 最初のページから：写真位置図（A3 横、全体図・分割図の順）。矢印と番号は Word 上で動かせる図形にするか、地図の画像に組み込むかを選べます。
   - 2 ページ目以降：写真台帳（A4 縦・1 ページ 3 枚、「■No.」と説明文）。
   - 保存するときに、ファイル名と保存先を選べます。
   - 文字のフォント（ＭＳ ゴシック・ＭＳ 明朝など）と文字の大きさを選べます。
   - 番号の表記（「■No.1」など）を、`■No.{番号}`・`写真{丸数字}` のようなひな形で一括して変えられます。

## 使い方

1. **Google Chrome** か **Microsoft Edge** で https://yamamotowt08.github.io/genchi-photo-tool/ を開きます。
   （`現地調査写真整理ツール.html` をダウンロードして開いても使えます）
2. 「フォルダを選ぶ」で写真の入ったフォルダを選び、変更を許可します。
3. ①〜③の順に作業します。Word ファイルは、ファイル名と保存先を選んで保存します。

### 社内サーバーに置く場合（部品入りの版）

`現地調査写真整理ツール_部品入り.html` は、地図表示（Leaflet）と Word 作成（JSZip）の部品を HTML の中に取り込んだ版です。
社内のネットワークで外部の部品の配信元が止められていても動きます（国土地理院の地図は、インターネットから読み込みます）。

- 社内の Web サーバーに置くときは、`https://` で開けるようにしてください（`http://` ではフォルダを読み書きする機能が使えません）。
- Edge の Internet Explorer モードの対象から外してください。
- ツールを直したら `python3 build_standalone.py` で部品入りの版を作り直します（部品は `vendor/` にあります）。

### 必要なもの

- パソコンの Google Chrome または Microsoft Edge（フォルダを直接操作する機能を使うため、Firefox・Safari・スマートフォンでは動きません）
- インターネット接続（地図と、ツールが使う部品を読み込むため）

## データの扱い

- 写真や入力内容は、選んだフォルダの中だけで扱います。どこかのサーバーに送ることはありません。
- 入力した説明や、直した位置・向きなどは、フォルダ内の `写真整理データ.json` に自動で保存されます。次に同じフォルダを開くと続きから作業できます。

## 地図の出典

地図には国土地理院の地理院タイルと、基盤地図情報（ベクトルタイル提供実験）を使っています。位置図には出典が自動で入ります。
基盤地図情報は国土地理院の試験配信のデータを使っているため、配信の内容が変わったり、終わったりすることがあります。
報告書などに使うときは、[国土地理院の利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)を確認してください。
